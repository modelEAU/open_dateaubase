**httpx mock transport:** Use `httpx.MockTransport` or `respx` — prefer httpx's built-in `MockTransport` to avoid adding a new test dependency.
  Pattern:
  ```python
  def mock_transport(routes: dict) -> httpx.MockTransport:
      # routes maps (method, path) → (status, json_body)
  ```
  Or use `httpx._transports.mock.MockTransport` with `httpx.Client(transport=mock_transport)`.
  Simplest approach: monkeypatch `app.api_client._get_client` to return a client with mock transport.
</context>

  <name>api_client public functions</name>
  <files>app/api_client.py, tests/app/test_api_client.py</files>
  <behavior>
    Expected behavior per function category:

    SUCCESS cases (mock API returns 200):
    - list_sites() with 200 → returns dict with "items" key
    - get_site(1) with 200 → returns dict with expected fields
    - create_site({"name": "Test"}) with 201 → returns created dict
    - delete_site(1) with 204 → returns None

    ERROR cases (mock API returns 4xx/5xx):
    - get_site(999) with 404 → raises APIError with status_code=404
    - create_site({}) with 422 → raises APIError with status_code=422
    - Any function when API is unreachable (ConnectError) → raises APIError with status_code=503

    INGESTION cases:
    - ingest_sensor(valid_data) with 201 → returns dict with "channel_id" and "rows_written"
    - ingest_lab(valid_data) with 201 → returns dict

    FILTER params:
    - list_channels(parameter_id=5) → request URL includes ?parameter_id=5
    - list_channels(parameter_id=None) → request URL does NOT include parameter_id param

    No need to test every single function if the pattern is proven — test a representative sample
    from each HTTP verb (GET list, GET single, POST, PUT, DELETE) plus all error paths.
    Cover ingestion functions explicitly since they're the most important business operations.
  </behavior>
  <implementation>
    Use pytest fixtures:
    1. A `mock_client` fixture that monkeypatches `app.api_client._get_client` to return an
       httpx.Client backed by a configurable mock transport.
    2. Helper `make_response(status, body)` that returns a mock httpx.Response.

    Preferred transport approach — use `httpx.MockTransport` with a handler:
    ```python
    import httpx

    def make_mock_client(handler):
        transport = httpx.MockTransport(handler)
        return httpx.Client(transport=transport, base_url="http://test")
    ```

    DO NOT use `responses`, `requests-mock`, or `respx` — avoid new test-only dependencies.
    DO NOT test private helpers (`_get_client`) directly — only public functions.
    DO NOT assert on exact URL strings — assert on behavior (return values, exceptions).
  </implementation>
</feature>
