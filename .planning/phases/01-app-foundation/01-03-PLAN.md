<task type="auto">
  <name>Task 1: Write app/auth.py — session-state auth stub</name>
  <files>app/auth.py</files>
  <action>
    Write app/auth.py with these public functions:

    `require_auth() -> None`
    - If `st.session_state.get("user")` is set: return immediately (user is logged in)
    - If not set: call `_show_login_page()` and `st.stop()` (halt page render)

    `get_current_user() -> dict | None`
    - Returns `st.session_state.get("user")` — a dict with at least {"name": str}

    `logout() -> None`
    - Clears `st.session_state["user"]`
    - Calls `st.rerun()` to refresh

    `_show_login_page() -> None` (private)
    - Renders a clean Streamlit login form:
      - Title: "open_datEAUbase"
      - Subtitle: "Water quality data management"
      - Username text input
      - Password text input (type="password")
      - "Sign in" button
    - On button click:
      ```python
      # TODO: Replace this block with real credential check (JWT, LDAP, etc.)
      if username and password:  # stub: any non-empty credentials work
          st.session_state["user"] = {"name": username}
          st.rerun()
      else:
          st.error("Please enter username and password.")
      ```
    - The TODO comment marks exactly where real auth goes. Keep it prominent.
    - DO NOT use st.experimental_user or any beta feature — keep it vanilla session_state.
    - IMPORTANT: `st.stop()` must be called AFTER `_show_login_page()`, not inside it.
      Inside _show_login_page, just render the form; let require_auth() call st.stop().
  </action>
