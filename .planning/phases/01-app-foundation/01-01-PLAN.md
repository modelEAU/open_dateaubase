<task type="auto">
  <name>Task 2: Write app/api_client.py — typed HTTP client for all API routes</name>
  <files>app/api_client.py</files>
  <action>
    Write a module with one function per API route the UI will use.
    Pattern:
    - Each function accepts typed Python arguments (no raw dicts as params)
    - Each function returns typed Python data (list[dict] or dict or None)
    - All functions use a shared `_get_client()` that returns `httpx.Client(base_url=settings.API_BASE_URL, timeout=30)`
    - On non-2xx response, raise `APIError(status_code, message)` — a simple Exception subclass defined at top of file
    - On connection error (httpx.ConnectError), raise `APIError(503, "Cannot reach API")`

    Functions to implement (mirror the API routes):

    # Health
    def get_health() -> dict

    # Sites
    def list_sites(page=1, page_size=100) -> dict          # returns PaginatedResponse shape
    def get_site(site_id: int) -> dict
    def create_site(data: dict) -> dict
    def update_site(site_id: int, data: dict) -> dict
    def delete_site(site_id: int) -> None

    # Equipment
    def list_equipment(page=1, page_size=100) -> dict
    def get_equipment(equipment_id: int) -> dict
    def create_equipment(data: dict) -> dict
    def update_equipment(equipment_id: int, data: dict) -> dict
    def delete_equipment(equipment_id: int) -> None

    # Campaigns
    def list_campaigns(page=1, page_size=100) -> dict
    def get_campaign(campaign_id: int) -> dict
    def create_campaign(data: dict) -> dict
    def update_campaign(campaign_id: int, data: dict) -> dict
    def delete_campaign(campaign_id: int) -> None

    # Channels
    def list_channels(parameter_id=None, equipment_id=None, processing_degree_id=None, page=1, page_size=100) -> dict
    def get_channel(channel_id: int) -> dict

    # Timeseries
    def get_timeseries(channel_id: int, start: str | None = None, end: str | None = None) -> dict

    # Annotations
    def list_annotations(channel_id: int | None = None) -> dict
    def create_annotation(data: dict) -> dict
    def update_annotation(annotation_id: int, data: dict) -> dict
    def delete_annotation(annotation_id: int) -> None

    # Ingestion
    def ingest_sensor(data: dict) -> dict
    def ingest_lab(data: dict) -> dict

    IMPORTANT: Use httpx (NOT requests) — it is already in the optional deps.
    DO NOT use async/await — keep sync to match the existing API style.
    DO NOT hardcode URLs — always use settings.API_BASE_URL from app/config.py.
    Pass filter params as httpx `params=` kwargs (never f-string into URLs).
  </action>
