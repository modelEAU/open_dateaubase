<objective>
Update the API ingestion path to create an Observation row before inserting
each value payload. All insert_* functions in value_repository.py and the
ingest-supporting functions in ingestion_repository.py are updated.

Purpose: The payload tables (Value, ValueVector, ValueMatrix, ValueImage)
no longer carry Channel_ID or Timestamp — these are only in Observation. Every
insert must now be a two-step write: INSERT Observation → get Observation_ID →
INSERT payload.

Output: Updated `api/v1/repositories/value_repository.py` and
`api/v1/repositories/ingestion_repository.py`.
</objective>
