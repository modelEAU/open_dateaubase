**Current v2.1.0 table structures (confirmed from migration script):**

ValueVector:
  PK: [PK_ValueVector] on (Channel_ID, Timestamp, ValueBin_ID)
  FKs: [FK_ValueVector_Channel] Channel_ID→Channel,
       [FK_ValueVector_ValueBin] ValueBin_ID→ValueBin
  Target: PK (Observation_ID, ValueBin_ID), drop Channel_ID + Timestamp,
          FK_ValueVector_ValueBin stays (ValueBin_ID column kept)

ValueMatrix:
  PK: [PK_ValueMatrix] on (Channel_ID, Timestamp, RowValueBin_ID, ColValueBin_ID)
  FKs: [FK_ValueMatrix_Channel], [FK_ValueMatrix_RowValueBin], [FK_ValueMatrix_ColValueBin]
  Target: PK (Observation_ID, RowValueBin_ID, ColValueBin_ID)

ValueImage:
  PK: [PK_ValueImage] on ValueImage_ID (BIGINT IDENTITY)
  UNIQUE: [UQ_ValueImage_ChannelTimestamp] on (Channel_ID, Timestamp)
  FK: [FK_ValueImage_Channel] Channel_ID→Channel
  Target: PK on Observation_ID (replaces ValueImage_ID as sole row identifier)

Pattern (identical for all three):
  1. INSERT DISTINCT (Channel_ID, Timestamp) into Observation with correct DataType
  2. ADD Observation_ID BIGINT NULL
  3. UPDATE Observation_ID via JOIN
  4. ALTER COLUMN NOT NULL
  5. DROP constraints that reference Channel_ID or the old PK
  6. DROP Channel_ID, Timestamp (and old IDENTITY PK column for ValueImage)
  7. ADD new PK + FK_*_Observation

-- ==============================================================
-- STEP 3: Backfill Observation from ValueVector; restructure as
--         lean payload keyed by (Observation_ID, ValueBin_ID)
-- ==============================================================

1. Backfill Observation for each unique (Channel_ID, Timestamp) in ValueVector:
   INSERT INTO [dbo].[Observation] ([Channel_ID], [Timestamp], [DataType])
   SELECT DISTINCT [Channel_ID], [Timestamp], 'Vector'
   FROM [dbo].[ValueVector];
   GO

2. Add Observation_ID:
   ALTER TABLE [dbo].[ValueVector] ADD [Observation_ID] BIGINT NULL;
   GO

3. Populate Observation_ID:
   UPDATE vv
   SET vv.[Observation_ID] = o.[Observation_ID]
   FROM [dbo].[ValueVector] vv
   JOIN [dbo].[Observation] o
       ON o.[Channel_ID] = vv.[Channel_ID]
      AND o.[Timestamp]  = vv.[Timestamp]
      AND o.[DataType]   = 'Vector';
   GO

4. Make NOT NULL:
   ALTER TABLE [dbo].[ValueVector] ALTER COLUMN [Observation_ID] BIGINT NOT NULL;
   GO

5. Drop old PK (blocks column drops):
   ALTER TABLE [dbo].[ValueVector] DROP CONSTRAINT [PK_ValueVector];
   GO

6. Drop FK on Channel_ID:
   ALTER TABLE [dbo].[ValueVector] DROP CONSTRAINT [FK_ValueVector_Channel];
   GO

7. Drop Channel_ID and Timestamp:
   ALTER TABLE [dbo].[ValueVector] DROP COLUMN [Channel_ID];
   ALTER TABLE [dbo].[ValueVector] DROP COLUMN [Timestamp];
   GO

8. New composite PK (Observation_ID, ValueBin_ID):
   ALTER TABLE [dbo].[ValueVector]
       ADD CONSTRAINT [PK_ValueVector] PRIMARY KEY ([Observation_ID], [ValueBin_ID]);
   GO

9. New FK Observation_ID → Observation:
   ALTER TABLE [dbo].[ValueVector]
       ADD CONSTRAINT [FK_ValueVector_Observation]
       FOREIGN KEY ([Observation_ID]) REFERENCES [dbo].[Observation] ([Observation_ID]);
   GO

   -- Note: FK_ValueVector_ValueBin is NOT dropped — ValueBin_ID column is unchanged.
