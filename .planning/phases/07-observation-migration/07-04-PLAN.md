**Target schemas after v2.2.0 migration:**

Observation:
  Columns: Observation_ID (BIGINT IDENTITY PK, NOT NULL), Channel_ID (INT NOT NULL FK→Channel),
           Timestamp (DATETIME2(7) NOT NULL), DataType (VARCHAR(10) NOT NULL, values: Scalar/Vector/Matrix/Image)

Value (v2.2.0):
  Columns: Observation_ID (BIGINT NOT NULL PK FK→Observation), Value (FLOAT nullable)
  Dropped: Value_ID, Channel_ID, Timestamp

  Columns: Observation_ID (BIGINT NOT NULL FK→Observation), ValueBin_ID (INT NOT NULL FK→ValueBin),

ValueMatrix (v2.2.0):
  Columns: Observation_ID (BIGINT NOT NULL FK→Observation), RowValueBin_ID (INT NOT NULL FK→ValueBin),
           ColValueBin_ID (INT NOT NULL FK→ValueBin), Value (FLOAT nullable), QualityCode (INT nullable)
  Dropped: Channel_ID, Timestamp
  PK: (Observation_ID, RowValueBin_ID, ColValueBin_ID)

ValueImage (v2.2.0):

Annotation (v2.2.0):

  <name>Task 1: Create Observation.yaml + update Value, ValueVector, ValueMatrix YAMLs</name>
  <files>

  <action>
1. CREATE schema_dictionary/tables/Observation.yaml:
   _format_version: "1.0"
   table:
     name: Observation
     schema: dbo
     description: "Shared hub table representing a single measurement event
       on a channel at a timestamp. The four payload tables (Value, ValueVector,
       ValueMatrix, ValueImage) carry only their type-specific data, keyed by
       Observation_ID. DataType mirrors Channel.ValueType_ID for self-description."
     columns:
       - name: Observation_ID
         logical_type: integer
         nullable: false
         identity: true
         description: "Surrogate key; auto-assigned by the database"
       - name: Channel_ID
         logical_type: integer
         nullable: false
         description: "The channel this observation belongs to"
         foreign_key:
           table: Channel
           column: Channel_ID
       - name: Timestamp
         logical_type: timestamp
         precision: 7
         nullable: false
         description: "UTC timestamp of the observation"
       - name: DataType
         logical_type: string
         nullable: false
         description: "Payload type: Scalar, Vector, Matrix, or Image.
           Must match the Channel's ValueType."
     primary_key: [Observation_ID]

2. REWRITE schema_dictionary/tables/Value.yaml:
   _format_version: "1.0"
   table:
     name: Value
     schema: dbo
     description: "Scalar payload for a single Observation. One row per
       Observation of DataType='Scalar'. Channel and Timestamp are resolved
       via the Observation table."
     columns:
       - name: Observation_ID
         logical_type: integer
         nullable: false
         description: "Links this scalar value to its Observation (channel + timestamp)"
         foreign_key:
           table: Observation
           column: Observation_ID
       - name: Value
         logical_type: float64
         nullable: true
         description: "Measured scalar value"
     primary_key: [Observation_ID]

3. REWRITE schema_dictionary/tables/ValueVector.yaml:
   (Read existing file first to preserve description intent, then rewrite columns)
   New columns: Observation_ID (BIGINT NOT NULL FK→Observation, PK part),
                ValueBin_ID (INT NOT NULL FK→ValueBin, PK part),
                Value (FLOAT nullable), QualityCode (INT nullable)
   PK: [Observation_ID, ValueBin_ID]
   Description: "One row per (observation, bin) for vector (spectral) data.
     Channel and Timestamp resolved via Observation."

4. REWRITE schema_dictionary/tables/ValueMatrix.yaml:
   New columns: Observation_ID (BIGINT NOT NULL FK→Observation, PK part),
                RowValueBin_ID (INT NOT NULL FK→ValueBin, PK part),
                ColValueBin_ID (INT NOT NULL FK→ValueBin, PK part),
                Value (FLOAT nullable), QualityCode (INT nullable)
   PK: [Observation_ID, RowValueBin_ID, ColValueBin_ID]
   Description: "One row per (observation, row-bin, col-bin) for 2D matrix data.
     Channel and Timestamp resolved via Observation."
  </action>
  <verify>
- All four files exist and have _format_version: "1.0".
- Observation.yaml: 4 columns, PK=[Observation_ID], FK Channel_ID→Channel.
- Value.yaml: 2 columns, PK=[Observation_ID], FK Observation_ID→Observation.
  No Channel_ID, no Timestamp, no Value_ID.
- ValueVector.yaml: 4 columns, PK=[Observation_ID, ValueBin_ID].
- ValueMatrix.yaml: 5 columns, PK=[Observation_ID, RowValueBin_ID, ColValueBin_ID].
  </verify>
  <done>Observation.yaml created; Value/ValueVector/ValueMatrix YAMLs updated to v2.2.0 structure.</done>
