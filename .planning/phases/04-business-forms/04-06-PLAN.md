<objective>
Create an enhanced lab ingest page that covers the full workflow: optionally create a
new sample inline, fill lab analysis metadata, enter per-parameter results with a
duplicate-row shortcut, and submit to POST /ingest/lab.

Purpose: Lab analyses are the primary mechanism for recording water quality results
from physical sampling events. The page must support the realistic workflow where a
student runs multiple replicates of the same parameter — hence the duplicate-row
feature — without needing to re-enter all metadata.
Output: app/pages/10_Lab_Ingest.py. Also adds POST /samples endpoint for inline
sample creation.
</objective>

**API contracts:**
  LabIngestRequest:
    sample_id: int | None
    laboratory_id: int | None
    analyst_person_id: int | None
    procedure_id: int | None
    campaign_id: int | None
    notes: str | None
    values: list[LabValueItem]  (parameter_id, unit_id, value, replicate, quality_code)

  Sample table (for inline creation):
    SamplingPoint_ID (required), SampledByPerson_ID (optional),
    Campaign_ID (optional), SampleDateTimeStart (required),
    SampleDateTimeEnd (optional), SampleMethod_ID (optional),
    Description (optional)
    Note: SampleType_ID and SampleEquipment_ID also exist but are optional

  Note: LabValue has no Unit_ID column in the DB — unit_id in LabValueItem schema
  is accepted but NOT stored (unit is on the Parameter). Pass it anyway; API ignores it.

Create app/pages/10_Lab_Ingest.py.

Structure:
1. Path setup + imports (copy from 9_Sensor_Ingest.py pattern)
   Import from api_client:
     ingest_lab, create_sample,
     list_campaigns_lookup, list_laboratories_lookup, list_procedures_lookup,
     list_samples_lookup, list_sampling_points_lookup, list_parameters_lookup,
     list_units_lookup, APIError

2. require_auth() + sidebar
3. st.title("Lab Analysis Ingest")
   st.markdown("Record the results of a laboratory analysis. Create a new sample or
   select an existing one, then enter measured values per parameter.")

4. Load all lookups at page top in a single try/except APIError block.
   Use st.spinner("Loading reference data...").

5. Sample section (st.container with border, label="Sample"):
   st.subheader("Sample")
   sample_mode = st.radio("Sample", ["Use existing sample", "Create new sample"],
                           horizontal=True, label_visibility="collapsed")

   "Use existing sample" mode:
     sample_options = [{"id": s["sample_id"], "label": s["label"]}
                       for s in samples_lookup]
     sample_options.insert(0, {"id": None, "label": "— none —"})
     selected_sample_label = st.selectbox("Select sample", ...)
     sample_id = resolve from options

   "Create new sample" mode:
     Two columns:
       col1: sampling_point selectbox (from list_sampling_points_lookup)
       col2: campaign selectbox (optional, from list_campaigns_lookup, include "None" option)
     Two columns:
       col1: start date (st.date_input) + start time (st.time_input)
       col2: end date (optional) + end time (optional)
     description text_area (optional)
     sampled_by_person_id number_input (optional, label="Analyst person ID (optional)")

     sample_id will be None until user clicks "Create Sample" button.
     "Create Sample" button:
       Calls create_sample({sampling_point_id, campaign_id, sample_datetime_start,
                            sample_datetime_end, sampled_by_person_id, description})
       On success: st.session_state["created_sample_id"] = result["sample_id"]
                   st.success(f"Sample {result['sample_id']} created")
       On error: st.error
     Use st.session_state["created_sample_id"] as sample_id going forward.

6. Analysis metadata section (st.container with border, label="Lab Analysis"):
   st.subheader("Analysis Metadata")
   Three columns:
     Laboratory: selectbox (list_laboratories_lookup, include "None" option)
     Procedure: selectbox (list_procedures_lookup, include "None" option)
     Analyst Person ID: st.number_input(min_value=1, step=1, value=None)
   Campaign: selectbox (list_campaigns_lookup, optional, include "None")
   Notes: st.text_area (optional)

7. Measurement values section (st.container with border, label="Measurements"):
   st.subheader("Measured Values")
   st.caption("Add one row per parameter measurement. Use 'Duplicate' to copy a row
   before changing its value — useful for replicates.")

   Use st.data_editor for measurements. Store rows in st.session_state["lab_rows"].
   Initialize with one empty row if not present:
     default_row = {"parameter_id": None, "unit_id": None, "value": None,
                    "replicate": 1, "quality_code": None}
     st.session_state.setdefault("lab_rows", [default_row.copy()])

   Build display DataFrame from st.session_state["lab_rows"].
   Use st.data_editor with:
     - column_config for parameter_id: st.column_config.SelectboxColumn(
         "Parameter", options={p["parameter_id"]: p["parameter_name"]
                               for p in parameters_lookup})
     - column_config for unit_id: SelectboxColumn("Unit",
         options={u["unit_id"]: u["unit"] for u in units_lookup})
     - value: NumberColumn("Value")
     - replicate: NumberColumn("Replicate", min_value=1, default=1)
     - quality_code: NumberColumn("Quality Code", required=False)
     num_rows="dynamic" to allow adding rows via the + button

   Row management buttons (below data_editor):
   col1, col2 = st.columns([1, 9])
   with col1:
     if st.button("Duplicate selected"):
       # Duplication: copy last edited row with replicate incremented by 1
       # Since st.data_editor doesn't expose selection, duplicate last row in session state
       if st.session_state["lab_rows"]:
         last = st.session_state["lab_rows"][-1].copy()
         last["replicate"] = (last.get("replicate") or 1) + 1
         st.session_state["lab_rows"].append(last)
         st.rerun()
   Note: use num_rows="dynamic" so data_editor handles row addition natively.
   After each edit of data_editor, sync back: st.session_state["lab_rows"] = edited_df.to_dict("records")

8. Submit section:
   valid_rows = [r for r in st.session_state["lab_rows"]
                 if r.get("parameter_id") and r.get("value") is not None]
   submit_disabled = len(valid_rows) == 0
   if st.button("Submit Lab Analysis", type="primary", disabled=submit_disabled):
     payload = {
       "sample_id": sample_id,
       "laboratory_id": laboratory_id,
       "analyst_person_id": analyst_person_id,
       "procedure_id": procedure_id,
       "campaign_id": campaign_id,
       "notes": notes,
       "values": [{"parameter_id": r["parameter_id"], "unit_id": r["unit_id"],
                   "value": r["value"], "replicate": r["replicate"] or 1,
                   "quality_code": r["quality_code"]} for r in valid_rows]
     }
     try:
       with st.spinner("Submitting..."):
         result = ingest_lab(payload)
       st.success(f"Lab analysis {result['lab_analysis_id']} created with "
                  f"{result['rows_written']} values.")
       del st.session_state["lab_rows"]  # reset for next entry
       st.rerun()
     except APIError as e:
       st.error(f"Ingest failed: {e.message}")
