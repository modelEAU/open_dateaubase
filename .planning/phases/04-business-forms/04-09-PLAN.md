<objective>
Add image ingest infrastructure: a configurable server-side upload directory, a
multipart POST /ingest/sensor-image endpoint that saves the file and records metadata
in ValueImage, and an Image tab on the sensor ingest page with a file uploader.

Purpose: Sensors like cameras, microscopes, and flow-cytometers produce image data.
The ValueImage table stores file path + image metadata (dimensions, format, size). This
plan wires up the full path from browser upload → file saved to disk → DB record created.
Output: Upload directory config, API endpoint, repository function, and Image tab in
9_Sensor_Ingest.py.
</objective>

**Tech stack available:** FastAPI (UploadFile, File), Pillow (available via uv), Streamlit
**Schema context:**
  ValueImage(Channel_ID, Timestamp, ImageWidth, ImageHeight, NumberOfChannels,
             ImageFormat, FileSizeBytes, StorageBackend, StoragePath,
             Thumbnail VARBINARY(MAX), QualityCode)
  StorageBackend default: 'FileSystem'
  StoragePath: relative path from upload root, e.g., "uploads/images/{channel_id}/{ts}.png"
  Thumbnail: optional small JPEG bytes (store None if Pillow not available)
**Constraining decisions:**
- [Phase 04-05]: 9_Sensor_Ingest.py already uses st.tabs; add "Image" as 4th tab
- Upload dir: configurable via API settings, default ./uploads/images relative to where
  uvicorn runs. Create directory on startup if not exists.
- Do NOT store file content in DB — only the path. This is explicit in ValueImage design.
- File naming: {channel_id}/{timestamp_iso}.{ext} — timestamp uses ISO format with
  colons replaced by hyphens for filesystem safety
</context>

In api/v1/endpoints/ingest.py, add:
  from fastapi import UploadFile, File, Form
  import os
  from pathlib import Path
  from datetime import datetime
  from PIL import Image as PILImage
  import io
  from api.config import settings

  @router.post("/sensor-image", response_model=ImageIngestResponse, status_code=201)
  def ingest_sensor_image(
      equipment_id: int = Form(...),
      parameter_id: int = Form(...),
      unit_id: int = Form(...),
      timestamp: str = Form(...),  # ISO datetime string
      quality_code: int | None = Form(None),
      data_provenance_id: int = Form(1),
      processing_degree_id: int = Form(1),
      image: UploadFile = File(...),
      conn=Depends(get_db)
  ):
    # 1. Parse timestamp
    try:
        ts = datetime.fromisoformat(timestamp)
    except ValueError:
        raise HTTPException(400, detail="timestamp must be ISO format (YYYY-MM-DDTHH:MM:SS)")

    # 2. Read image bytes
    image_bytes = image.file.read()
    file_ext = Path(image.filename).suffix.lower().lstrip(".") or "bin"

    # 3. Get image metadata using Pillow
    try:
        pil_img = PILImage.open(io.BytesIO(image_bytes))
        width, height = pil_img.size
        n_channels = len(pil_img.getbands())
        img_format = pil_img.format or file_ext.upper()
        # Generate thumbnail (100x100 max, JPEG bytes)
        thumb = pil_img.copy()
        thumb.thumbnail((100, 100))
        thumb_buf = io.BytesIO()
        thumb.convert("RGB").save(thumb_buf, format="JPEG")
        thumbnail_bytes = thumb_buf.getvalue()
    except Exception:
        # Pillow failed — store without metadata
        width, height, n_channels = 0, 0, 0
        img_format = file_ext.upper()
        thumbnail_bytes = None

    # 4. Find/create channel (value_type_id=4 = Image)
    channel_id = find_or_create_sensor_metadata(
        conn, equipment_id=equipment_id, parameter_id=parameter_id,
        unit_id=unit_id, data_provenance_id=data_provenance_id,
        processing_degree_id=processing_degree_id, value_type_id=4)

    # 5. Save file to disk
    ts_safe = ts.isoformat().replace(":", "-")
    rel_path = f"uploads/images/{channel_id}/{ts_safe}.{file_ext}"
    abs_path = Path(settings.UPLOAD_DIR).parent / rel_path
    abs_path.parent.mkdir(parents=True, exist_ok=True)
    abs_path.write_bytes(image_bytes)

    # 6. Insert DB record
    value_image_id = insert_image_value(
        conn, channel_id=channel_id, timestamp=ts,
        image_width=width, image_height=height, number_of_channels=n_channels,
        image_format=img_format, file_size_bytes=len(image_bytes),
        storage_path=rel_path, quality_code=quality_code,
        thumbnail=thumbnail_bytes)

    return ImageIngestResponse(channel_id=channel_id,
                               value_image_id=value_image_id,
                               storage_path=rel_path)
