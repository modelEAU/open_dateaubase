EquipmentModel CRUD:

In api/v1/schemas/equipment.py (or create if needed), add:
  class EquipmentModelIn(BaseModel):
    equipment_model: str | None = None
    method: str | None = None
    functions: str | None = None
    manufacturer: str | None = None
    manual_location: str | None = None

In api/v1/repositories/equipment_repository.py, add:
  list_equipment_models(conn) → list[dict] — SELECT all from EquipmentModel
  get_equipment_model_by_id(conn, model_id) → dict | None
  insert_equipment_model(conn, data: dict) → int — INSERT + SELECT @@IDENTITY
  update_equipment_model(conn, model_id, data: dict) → None — UPDATE
  delete_equipment_model(conn, model_id) → None — DELETE

In api/v1/endpoints/equipment.py, add routes under the existing equipment router:
  GET  /equipment/models        → list_equipment_models
  GET  /equipment/models/{id}   → get_equipment_model_by_id (404 if None)
  POST /equipment/models        → insert_equipment_model, status_code=201
  PUT  /equipment/models/{id}   → update_equipment_model
  DELETE /equipment/models/{id} → delete_equipment_model, status_code=204

Parameter CRUD:

In api/v1/schemas/channel.py, add:
  class ParameterIn(BaseModel):
    parameter: str
    unit_id: int | None = None
    description: str | None = None

Create api/v1/endpoints/parameters.py with a new APIRouter():
  GET  /parameters        → list all from [dbo].[Parameter]
  GET  /parameters/{id}   → get by id
  POST /parameters        → insert, status_code=201
  PUT  /parameters/{id}   → update
  DELETE /parameters/{id} → delete, status_code=204

Repository functions in api/v1/repositories/metadata_repository.py:
  list_parameters(conn) → list[dict]  (full rows, not just lookup)
  get_parameter_by_id(conn, param_id) → dict | None
  insert_parameter(conn, data: dict) → int
  update_parameter(conn, param_id, data: dict) → None
  delete_parameter(conn, param_id) → None

Register in api/v1/router.py:
  from .endpoints.parameters import router as parameters_router
  router.include_router(parameters_router, prefix="/parameters", tags=["parameters"])

In app/api_client.py add (EquipmentModels section):
  list_equipment_models() → dict (paginated or list)
  create_equipment_model(data: dict) → dict
  update_equipment_model(model_id: int, data: dict) → dict
  delete_equipment_model(model_id: int) → None

Add (Parameters section):
  list_parameters_full() → list[dict]  (distinct from list_parameters_lookup)
  create_parameter(data: dict) → dict
  update_parameter(param_id: int, data: dict) → dict
  delete_parameter(param_id: int) → None
