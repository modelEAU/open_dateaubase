5. Channel identification section (st.container with border):
   st.subheader("Channel Identity")
   Three columns:
   - Equipment: st.selectbox, options from list_equipment_lookup(), label=identifier
   - Parameter: st.selectbox, options from list_parameters_lookup(), label=parameter_name
   - Unit: st.selectbox, options from list_units_lookup(), label=unit
   Two columns below:
   - Data Provenance: st.selectbox(["Sensor (1)", "Laboratory (2)", "Manual Entry (3)"],
     index=0) → extract int from selection
   - Processing Degree: st.selectbox(["Raw (1)", "Cleaned (2)", "Validated (3)"],
     index=0) — if only 3 options known; show "(auto-created if new)" note

6. Data input section (st.container with border):
   st.subheader("Data")
   Input mode = st.radio("Input method", ["Paste CSV", "Upload CSV file"],
                          horizontal=True)

   Paste CSV mode:
     st.text_area with placeholder:
       "timestamp,value,quality_code
       2024-01-15T08:00:00,7.42,
       2024-01-15T08:15:00,7.45,"
     st.caption("ISO timestamps (YYYY-MM-DDTHH:MM:SS). quality_code column optional.")

   Upload CSV mode:
     uploaded = st.file_uploader("Choose CSV file", type=["csv"])
     If uploaded: read as text (uploaded.read().decode("utf-8"))

7. Parse and preview:
   Parse on st.button("Preview") or whenever raw_csv changes (use st.session_state):
   Use Python csv.reader to parse rows.
   Expected columns: timestamp, value, [quality_code] — header row auto-detected.
   Parsing logic:
     - Strip BOM if present
     - Detect header: if first cell lower() in {"timestamp", "datetime", "time"}: skip
     - For each data row: parse timestamp with datetime.fromisoformat(),
       value as float (None if empty/nan), quality_code as int (None if empty)
     - Collect parse errors (row index + message) separately
   If errors > 0: st.warning(f"{len(errors)} rows had parse errors and will be skipped.")
     Show errors in st.expander("Parse errors")
   If valid rows > 0:
     preview_df = pd.DataFrame(valid_rows[:20])  — first 20
     st.dataframe(preview_df, use_container_width=True)
     st.caption(f"{len(valid_rows)} valid rows total. Showing first 20.")

8. Submit section:
   submit_disabled = len(valid_rows) == 0 or equipment_id is None or parameter_id is None
   if st.button("Submit to Database", disabled=submit_disabled, type="primary"):
     payload = {
       "equipment_id": equipment_id,
       "parameter_id": parameter_id,
       "unit_id": unit_id,
       "data_provenance_id": data_provenance_id,
       "processing_degree_id": processing_degree_id,
       "values": [{"timestamp": r["timestamp"].isoformat(), "value": r["value"],
                   "quality_code": r["quality_code"]} for r in valid_rows]
     }
     try:
       with st.spinner("Submitting..."):
         result = ingest_sensor(payload)
       st.success(f"Ingested {result['rows_written']} rows into channel {result['channel_id']}.")
       st.info("Channel was auto-created." if result.get("channel_id") else "")
     except APIError as e:
       st.error(f"Ingest failed: {e.message}")

Store parse state in st.session_state["parsed_rows"] and st.session_state["parse_errors"]
to avoid re-parsing on every widget interaction.
