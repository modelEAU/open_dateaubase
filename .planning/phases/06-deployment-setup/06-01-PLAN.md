<task type="auto">
  <name>Task 1: Create Dockerfile.api</name>
  <files>Dockerfile.api</files>
  <action>
Create a new file `Dockerfile.api` (do NOT modify the legacy `Dockerfile`). Use `python:3.12-slim` as base (not 3.11). Steps:

1. Set ENV: PYTHONUNBUFFERED=1, PYTHONDONTWRITEBYTECODE=1
2. WORKDIR /app
3. Install OS deps: curl, ca-certificates, gcc, g++, unixodbc, unixodbc-dev, gnupg
4. Install MSSQL ODBC 18 via Microsoft apt repo (same pattern as existing Dockerfile):
   - Add Microsoft GPG key to /usr/share/keyrings/microsoft-prod.gpg
   - Add Microsoft prod.list for debian/12
   - apt-get install ACCEPT_EULA=Y msodbcsql18
5. Install uv: `pip install uv`
6. Copy pyproject.toml and uv.lock first (for layer caching)
7. Copy src/ (needed so uv can install the open_dateaubase package from source)
8. Run: `uv sync --extra api` (installs fastapi, uvicorn, pyodbc, python-dotenv, and the local src package)
9. Copy the rest of the project (. /app), excluding heavy dirs via .dockerignore
10. Set ENV: PATH="/app/.venv/bin:$PATH" (uv creates .venv in project dir by default)
11. EXPOSE 8000
12. CMD: ["uv", "run", "uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]

Note: uploads dir is mounted via volume in compose — no need to create it in image.
Note: Do NOT add --reload flag in CMD (production mode).
  </action>
  <verify>docker build -f Dockerfile.api -t dateaubase-api:test . 2>&1 | tail -5</verify>
  <done>Build exits 0, image tagged dateaubase-api:test present in `docker images`</done>

<task type="auto">
  <name>Task 2: Create Dockerfile.app</name>
  <files>Dockerfile.app</files>
  <action>
Create `Dockerfile.app` for the Streamlit frontend. Use `python:3.12-slim` as base. Steps:

1. Set ENV: PYTHONUNBUFFERED=1, PYTHONDONTWRITEBYTECODE=1
2. WORKDIR /app
3. Install OS deps (minimal — no ODBC): curl, ca-certificates (needed for httpx HTTPS)
4. Install uv: `pip install uv`
5. Copy pyproject.toml and uv.lock
6. Copy src/ (local package dependency)
7. Run: `uv sync --extra app` (installs streamlit, httpx, plotly — no pyodbc, no ODBC driver)
8. Copy app/ directory
9. Set ENV: PATH="/app/.venv/bin:$PATH"
10. Set ENV: API_BASE_URL="http://api:8000/api/v1" (default for Docker compose; overridable)
11. EXPOSE 8501
12. CMD: ["uv", "run", "streamlit", "run", "app/Home.py", "--server.port=8501", "--server.address=0.0.0.0", "--server.headless=true"]

Note: `--server.headless=true` disables the browser-open prompt in container context.
Note: No MSSQL ODBC driver installed — app talks to API over HTTP only.
