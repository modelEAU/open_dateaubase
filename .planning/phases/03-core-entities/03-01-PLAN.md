  </files>
  <action>
    Add three write functions to api/v1/repositories/channel_repository.py following the pattern from site_repository.py and equipment_repository.py:

    1. insert_channel(conn, data: dict) -> dict:
       - Execute INSERT into dbo.Channel with parameterized query
       - Use SELECT @@IDENTITY to get new Channel_ID (per project convention)
       - Call conn.commit()
       - Return get_channel_by_id(conn, new_id)

    2. update_channel(conn, channel_id: int, data: dict) -> dict | None:
       - Execute UPDATE with parameterized WHERE Channel_ID = ?
       - Call conn.commit()
       - Return get_channel_by_id(conn, channel_id) (returns None if not found)

    3. delete_channel(conn, channel_id: int) -> bool:
       - Execute DELETE FROM dbo.Channel WHERE Channel_ID = ?
       - Call conn.commit()
       - Return cursor.rowcount > 0

    Use parameterized queries throughout to prevent SQL injection.
  </action>
