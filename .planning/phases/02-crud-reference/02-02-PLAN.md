**Tech stack available:** FastAPI, pyodbc, Pydantic v2
**Established patterns:**
- Same write pattern as 02-01: parameterized `?` queries, `conn.commit()`, `cursor.execute("SELECT @@IDENTITY")` for new ID, then re-fetch full row via get_*_by_id
- INSERT returns new record via SELECT @@IDENTITY + re-fetch; UPDATE returns None when row missing; DELETE returns bool
- Endpoints: POST → 201, PUT → 200 (or 404), DELETE → 204 (or 404)

**Constraining decisions:**
- [Phase 01]: Always parameterized queries — never f-string SQL for user input
- Equipment: `EquipmentModel_ID` is a FK to EquipmentModel table — accept as nullable int in EquipmentIn (user provides ID, not name)
- Campaigns: `CampaignType_ID` and `Site_ID` are FKs — accept as int in CampaignIn (dropdowns in UI will provide valid IDs from API)
</context>

    ```python
        identifier: str | None = None
        serial_number: str | None = None
        model_id: int | None = None
        owner: str | None = None
        purchase_date: str | None = None  # ISO date string, e.g. "2024-01-15"
    ```

    In `api/v1/repositories/equipment_repository.py`, add:

    `insert_equipment(conn, data: dict) -> dict` — INSERT INTO [dbo].[Equipment] ([Identifier], [SerialNumber], [EquipmentModel_ID], [Owner], [PurchaseDate]) VALUES (?, ?, ?, ?, ?); SELECT @@IDENTITY; return get_equipment_by_id(conn, new_id).

    `update_equipment(conn, equipment_id: int, data: dict) -> dict | None` — UPDATE [dbo].[Equipment] SET [Identifier]=?, [SerialNumber]=?, [EquipmentModel_ID]=?, [Owner]=?, [PurchaseDate]=? WHERE [Equipment_ID]=?; conn.commit(); return get_equipment_by_id(conn, equipment_id).

    `delete_equipment(conn, equipment_id: int) -> bool` — DELETE FROM [dbo].[Equipment] WHERE [Equipment_ID]=?; conn.commit(); return cursor.rowcount > 0.

    In `api/v1/endpoints/equipment.py`, add three endpoints (import EquipmentIn from schemas):
    ```python
    @router.post("", response_model=EquipmentOut, status_code=201)
    def create_equipment(body: EquipmentIn, conn=Depends(get_db)):
        return equipment_repository.insert_equipment(conn, body.model_dump())

    @router.put("/{equipment_id}", response_model=EquipmentOut)
    def update_equipment(equipment_id: int, body: EquipmentIn, conn=Depends(get_db)):
        updated = equipment_repository.update_equipment(conn, equipment_id, body.model_dump())
        if updated is None:
            raise HTTPException(status_code=404, detail=f"Equipment {equipment_id} not found.")
        return updated

    @router.delete("/{equipment_id}", status_code=204)
    def delete_equipment(equipment_id: int, conn=Depends(get_db)):
        if not equipment_repository.delete_equipment(conn, equipment_id):
            raise HTTPException(status_code=404, detail=f"Equipment {equipment_id} not found.")
    ```
